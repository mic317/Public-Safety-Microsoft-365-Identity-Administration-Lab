Officer Offboarding Workflow
This section contains screenshots and documentation for offboarding personnel in the Public Safety Microsoft 365 & Identity Administration Lab.

Scenario
Officer Jones separates from the Castle Rock Public Safety Agency.

Deprovisioning Process
Disable User Account
Remove Group Memberships
Remove Microsoft 365 License
Revoke Active Sessions
Archive Required Data
Document Account Closure
Outcome
Access is removed in accordance with Identity Governance policies and the principle of least privilege.
