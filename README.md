Public Safety Microsoft 365 & Identity Administration Lab

Overview

This project simulates a public safety environment utilizing Microsoft Entra ID, Microsoft 365, Microsoft Intune, SharePoint Online, Microsoft Teams, Conditional Access, Multi-Factor Authentication (MFA), Role-Based Access Control (RBAC), and Identity Governance.

The objective of this lab is to demonstrate identity administration, access management, user lifecycle management, endpoint management, and security controls commonly used within public safety and government organizations.
